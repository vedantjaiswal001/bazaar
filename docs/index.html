Intent → signed mandate

A natural-language request is compiled into a structured mandate. The human confirms the rendered mandate before it is signed - so a bad parse can never become a signed, "valid" boundary.

Bounded negotiation → deterministic settlement

One negotiation round, clamped between the buyer's cap and the seller's floor - both visible. The authoritative price comes from the merchant of record, never the seller's word.

The deterministic authorization gate

A fixed checklist. All checks pass → ALLOW. Any check fails → BLOCK with exactly one machine-readable reason code - never "the AI decided no."

Run a purchase or fire an attack to populate the checklist.

Trust Receipt - verifiable, tamper-evident

Every decision emits a canonical-JSON, cryptographically signed receipt. Verify it - it passes. Change one field - it fails. The cryptography is real (signed live in your browser), not decorative.

Run a purchase or attack first to produce a receipt.

Red-team harness - nine attack classes, live

Fire attacks at the live gate. Each returns a specific reason code - measured, not asserted.
